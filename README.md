# robotMatic CNC Automatizaciones

Sitio web institucional de **robotMatic CNC Automatizaciones**.

## Dirección oficial

**Martín Peschel 1630, Loma Hermosa, B1657, Buenos Aires, Argentina.**

## Primera versión

La web está construida como sitio estático, sin dependencias de compilación:

- `index.html` — estructura y contenido.
- `styles.css` — diseño responsive y estética industrial/tecnológica.
- `script.js` — navegación móvil, cabecera dinámica y animaciones de entrada.

## Publicación con GitHub Pages

El sitio puede publicarse directamente desde este repositorio mediante GitHub Pages:

1. Abrir **Settings** del repositorio.
2. Entrar en **Pages**.
3. En **Build and deployment**, seleccionar **Deploy from a branch**.
4. Seleccionar la rama `main` y la carpeta `/ (root)`.
5. Guardar.
